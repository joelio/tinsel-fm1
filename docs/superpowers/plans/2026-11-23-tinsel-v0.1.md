# Tinsel v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tinsel v0.1 on a real FM-1 by Sunday 29 November 2026: the Grotto, the Sleigh menu, the Carol Book, Present Catch, the Advent calendar (doors 1 to 7), the grown-up panel, the volume cap, the bell sounds and reverb, and its own safe store; a mid-week test build (about 25 November) first.

**Architecture:** One unity build like Dinghy: `firmware/src/tinsel.c` includes `platform.c`, then Tinsel's headers. Pure parts (sound engine, carol player, Advent rules, game logic, store layout) are headers with no platform calls, so `tests/tn_test.c` includes them on the host. Drawing goes into an 8-bit indexed 240 × 240 frame in the pool, flushed to the panel band by band (only dirty bands), expanded through a 256-entry RGB565 palette. The sound engine runs in `app_audio`; the main loop talks to it through a one-writer request ring.

**Tech Stack:** C (JieLi clang, `-Os`, integers only), Python 3 + Pillow for generators, the Dinghy platform, fm1-emu.

**Spec:** `docs/DESIGN.md` (approved 23 November 2026), `docs/RESEARCH-NOTES.md`.

## Global Constraints

- Integers only; no 64-bit division; 64-bit multiplies only in `noinline` helpers, never in per-sample loops.
- `app_audio` under 2.9 ms per 256-frame block at the peak (fm1-emu `FM1_STRICT=1`); no flash, screen or polling in it.
- `platform_poll()` at least every few ms; save only when silent; never save in a loop.
- No register access outside `firmware/hal/`.
- Store window **0xB7000..0xDFFFF** only (settings 0xB7000, blobs 0xB8000..0xBFFFF, slots 0xC0000..0xDFFFF); magic "TNSL" (0x4C534E54).
- Identity **FM-1_902** for every release; `SCREEN_NAME` "TINSEL"; `SCREEN_COLOUR` tinsel gold; `DATA_FAMILY` "TINSEL".
- HOME always returns to the Grotto; the grown-up gesture is EDIT + SAVE held 2 s; nothing outside the panel changes a setting or deletes anything.
- Little Elf (default level) never fails, never speeds up.
- Only melodies from DESIGN section 11; our own transcriptions in `music/`, each with its source line.
- Default output ceiling "gentle" = 50 % of full scale (Q15 16384); medium 70 %; full 100 %.
- No commit of voice clips (`private/` is gitignored); a text-to-speech key only from the local keychain, never in the repo.

## Review Focus

1. Mashing all 27 keys and every button at once in any screen: no crash, no stuck notes, sound stays under the ceiling. Test: `tn_test` renders the engine with 27 simultaneous pings plus sleigh bells and a fanfare and asserts the peak ≤ ceiling and no voice leak after 5 s.
2. HOME pressed mid-anything (mid-carol, mid-catch, in the panel, during the boot plate): back to the Grotto, all notes released. Test: host script `tests/scripts/tinsel.txt` presses HOME in each screen; `tn_test` checks the scene machine's `scene_home()` releases voices.
3. Power-on with an empty store, a store from another firmware, or a store from an older Tinsel (a different settings size): defaults, no crash, nothing written outside the window. Test: `tn_test` store cases plus `FL_RANGE_OK` asserts.
4. A date that arrives twice, out of order, malformed, or before December (or after the 25th): doors never close, never open beyond the date, bad frames ignored. Test: Advent unit tests.
5. Holding EDIT alone, SAVE alone, or EDIT + SAVE for under 2 s (a toddler's grab): never enters the panel. Test: `tn_test` gesture timing cases.

### Task 3: The sound engine (`firmware/src/tn_snd.h`)

**Interfaces — Produces:**
- `enum tn_inst { TI_HANDBELL, TI_CHURCH, TI_CELESTA, TI_MUSICBOX, TI_GLOCK, TI_SOFTBASS, TI_PAD, TI_CHIME, TN_NINST };`
- `static void snd_ping(uint32_t inst, uint32_t midi, uint32_t vel /*0..127*/, int32_t pan /*-64..64*/);`
- `static void snd_shake(uint32_t strength /*0..127*/);` (sleigh bells)
- `static void snd_fx(uint32_t which);` with `SFX_FANFARE, SFX_SPARKLE, SFX_POP, SFX_WHOOSH, SFX_CHEER, SFX_DOOR`.
- `static void snd_release_all(void);` `static void snd_render(int32_t *out, uint32_t n);` `static void snd_set_ceiling(uint32_t q15);` `static void snd_set_reverb(uint32_t amount /*0..255*/);`
- Main-loop calls go through a 64-entry request ring read at the start of `snd_render` (one writer each side).
- [ ] Tests in `tests/tn_test.c`: each instrument renders non-silent, decays to silence within its T60 + 1 s; pitch of a TI_HANDBELL A4 within 1 % of 440 Hz by zero crossings; 27 pings + shake + fanfare: peak ≤ ceiling at every ceiling; `snd_release_all` silences within 50 ms; voice stealing never leaves more than `TN_VOICES` (16) active.
- [ ] Implement: 16 voices of up to 4 partials each (Melisma's parabola sine, 32-bit phases, per-partial Q15 decay applied every 32 frames, a short attack ramp), recipes from RESEARCH-NOTES section 5 (church bell uses 4 partials: hum 0.5, prime 1, tierce 1.183, nominal 2); PhISEM sleigh bells (5 resonators in Q30 coefficients, integer decays 32748 / 31785); a 4-line FDN reverb (1931, 2467, 2971, 3533 int16 in the pool, Hadamard mix, damping); the ceiling as a final clamp plus a slow limiter gain.
- [ ] Tests pass; commit.

### Task 4: The carols (`music/*.txt`, `tools/gen_music.py`, `firmware/gen/tn_music.h`, `firmware/src/tn_carol.h`)

**File format** (one carol per file): `title:`, `source:`, `meter:` (`4/4`, `3/4`, `6/8`), `tempo:` (crotchets or dotted crotchets a minute), `picture:` (a sprite name), `tune:` tokens `PITCH:DUR` (`E4:2`, unit = a quaver; `r:2` a rest) with `|` bar lines, `chords:` tokens `NAME:DUR` (`C`, `G7`, `Am`, `F`, ... in the written key) with `|`.

**Interfaces — Produces:** `typedef struct { const char *title; uint8_t meter, picture; uint16_t tempo, n, nchord; const uint8_t *pitch /*MIDI*/, *dur; const uint8_t *chord_root, *chord_kind, *chord_dur; } tn_carol_t; static const tn_carol_t TN_CAROLS[]; #define TN_NCAROLS`. Player (`tn_carol.h`): `typedef struct {...} carol_play_t; static void carol_start(carol_play_t *p, uint32_t which, uint32_t mode /*CM_MAGIC, CM_FOLLOW, CM_LISTEN*/); static int carol_key(carol_play_t *p, uint32_t key /*0..26*/, uint32_t now_ms); static void carol_tick(carol_play_t *p, uint32_t now_ms, tn_events_t *ev); static int carol_next_key(const carol_play_t *p, int ahead);` emitting note events for the melody and the backing.
- [ ] Tests: generator rejects a bar that does not sum to the meter, a chord line that does not match the tune's length, a missing source line, a range wider than 26 semitones; every shipped carol after transposition lies within F3..G5 (MIDI 53..79); Magic mode: any key advances exactly one note; Follow: a wrong key does not advance, the right key does; Listen: advances by time; the end of the tune raises `done` and never wraps silently.
- [ ] Write 10 carols: Jingle Bells (chorus), We Wish You a Merry Christmas, Deck the Halls, Away in a Manger (Cradle Song), Silent Night, Good King Wenceslas, O Christmas Tree, The First Nowell (verse and refrain), Joy to the World, Hark the Herald. Each `source:` names the traditional or composer source and says "transcribed by ear for Tinsel; to check against a pre-1930 print".
- [ ] Tests pass; commit.
